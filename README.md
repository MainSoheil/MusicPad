# 🎵 MusicPad

A simple web-based music pad for playing drums, beats, and sounds directly in your browser.

MusicPad provides an interactive pad interface where each button triggers a different sound. It is built with vanilla HTML, CSS, and JavaScript without using any frameworks.

## ✨ Features

* 🎹 Interactive sound pads
* 🥁 Multiple drum and instrument sounds
* ⚡ Fast sound playback using the Web Audio API
* 🎨 Dark, modern interface
* 📱 Responsive layout
* 🔊 Multiple sounds can be played simultaneously
* 🌐 Runs directly in the browser
* 🚀 No frameworks or external dependencies

## 🎧 Available Sounds

MusicPad currently includes:

* Kick
* Sub
* Snare
* Hi-Hat
* Clap
* Reese
* Wobble
* Pluck
* Solo
* Chord

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Web Audio API

## 🚀 Getting Started

MusicPad is a static website, so no installation or build process is required.

### 1. Clone the repository

```bash
git clone https://github.com/MainSoheil/MusicPad.git
```

### 2. Open the project

Open `index.html` in your browser.

Alternatively, use a local development server such as VS Code's Live Server extension.
